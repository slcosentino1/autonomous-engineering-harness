# Implement One Increment Prompt

Implement only the authorized increment in the identified target repository.

1. Re-read target instructions, applicable requirements/decisions, the increment plan, and working-tree status.
2. Confirm scope and acceptance criteria. Preserve unrelated and pre-existing changes.
3. Make the smallest maintainable change consistent with local conventions; add or update focused tests.
4. Do not add dependencies, infrastructure, or product behavior outside approved scope. Ask only when a real requirement or architecture decision is needed.
5. Run authorized validations that are available. Record exact commands and observed outcomes; distinguish blocked checks from passes.
6. Correct confirmed defects in scope and rerun affected checks.
7. Update the target's tracking artifacts with actual changes, evidence, limitations, and status.
8. Do not start the next increment until the required review/approval boundary is satisfied.

Report changed files, behavior, tests and results, remaining risks/blockers, and repository status. Do not claim completion without evidence for every required criterion.

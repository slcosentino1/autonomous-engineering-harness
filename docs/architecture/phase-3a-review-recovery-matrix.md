## Current checkpoint order

`Orchestrator._call_claude_impl` saves submitted context and operation before setting/saving `launching`; real `claude_reviewer.review` reports PID before collecting output; terminal context/operation/accounting are saved before `ReviewCampaign` saves the validated part. The interval between terminal result save and campaign checkpoint is recoverable today, but the normal fallback does not verify all provider-operation identity metadata.
